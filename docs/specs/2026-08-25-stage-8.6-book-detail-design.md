# Stage 8.6 — Book detail + curation (design)

- **Date:** 2026-08-25
- **Status:** For review
- **Depends on:** Stage 8.5 (book-first model). Build after 8.5 wraps (admin auto-promote add + T14 docs/PR).
- **Branch:** decide at kickoff — continue on `feature/8.5-book-first-refactor` or a fresh `feature/8.6-book-detail`.

## 1. Context & motivation

Stage 8.5 made **books** first-class (per-book status, book-first suggestions, a public `/books` catalog). This stage turns each book into a small **curated page** — Danny's synopsis, favourite quotes, and buy links — to drive **engagement** and enable **affiliate monetization**.

Most of the infrastructure already exists:

- `books.description_es/en` — the **synopsis**, already captured at promote time (`BookFields`).
- `book_links` table (`retailer` enum, `url`, `affiliate_tag`, `locale`) — the **buy-link / affiliate rail**, built in Stage 1, with no UI yet.
- `suggestion_books.linked_book_id` — ties a promoted book back to the suggester (enables the future "email the suggester" refinement).

The genuinely new work: a **quotes** table, an **admin book-content editor**, a **public book-detail page**, and making catalog rows **clickable**.

## 2. Goals (in scope)

1. **`book_quotes`** table — bilingual passage + optional location — with public-read / admin-manage RLS.
2. **Admin book-detail editor** — `/admin/books` rows gain an **Edit** affordance → a page to edit the **synopsis** + **quotes (1..N)** + **buy links**, DeepL-assisted, admin RLS.
3. **Public book-detail page** — catalog rows clickable → a **client-rendered, read-only** detail page (anon client, published-only via RLS) showing cover · title · author · year · original language · country · status · synopsis · quotes · buy links.
4. **Monetization done right** — buy links open in a new tab with `rel="sponsored nofollow noopener"`; a **contextual affiliate disclosure** shown only when ≥1 buy link exists; a privacy-policy line.

## 3. Out of scope / future refinements

- **"Email the suggester a quote"** (feasibility below) — deferred.
- **Pretty `/books/<slug>` URLs** — see §7; deferred to a Stage 9 concern (needs a slug column + rebuild-on-publish, or a Cloudflare rewrite).
- Author detail pages; book cover **uploads** (URL field only, as today); full book delete/CRUD.

### Feasibility note — "email the suggester a quote" (future)

**Feasible, medium effort.** The data link exists: `suggestion_books.linked_book_id` → the book; the parent `suggestions` row carries `submitter_email`, `accepted_newsletter`, `locale`. Reuse the **Resend + `email.ts`** pattern (as in `notify_submitter`). Recommended shape: a **manual admin action** ("Share this quote with the suggester") rather than an auto-send — it avoids spam and keeps Danny in editorial control — **gated on `accepted_newsletter`** (the GDPR consent basis is already captured at submit time). A book may be linked from more than one suggestion entry; pick the earliest opted-in suggester, or let the admin choose. Not built in 8.6.

## 4. Data model

### New: `book_quotes`

```sql
create table public.book_quotes (
  id            uuid primary key default gen_random_uuid(),
  book_id       uuid not null references public.books(id) on delete cascade,
  quote_es      text not null,
  quote_en      text not null,
  location      text,            -- "p. 42", "cap. 3" — nullable, language-neutral
  display_order int  not null default 0,
  created_at    timestamptz not null default now()
);
create index book_quotes_book_order_idx on public.book_quotes (book_id, display_order);

alter table public.book_quotes enable row level security;

-- Public read only when the book's author is published (mirrors book_links posture).
create policy "book_quotes for published authors"
  on public.book_quotes for select to anon, authenticated
  using (exists (
    select 1 from public.books b join public.authors a on a.id = b.author_id
    where b.id = book_quotes.book_id and a.published
  ));

create policy "admins manage book_quotes"
  on public.book_quotes for all to authenticated
  using (public.is_admin()) with check (public.is_admin());
```

`quote_es` + `quote_en` are both **NOT NULL**; the DeepL button fills the second from the first (same UX as the bios). If a passage should exist in only one language, the admin duplicates it — kept simple; revisit if it proves annoying (Open decision §8.3).

### Reused (no schema change)

- **Synopsis** → `books.description_es/en` (already captured at promote).
- **Buy links** → `book_links` (`retailer` enum `amazon|bookshop|kobo|other`, `url`, `affiliate_tag`, `locale`). RLS already public-read / admin-manage.

## 5. Admin flow — "go to the book and add content"

- **`/admin/books`**: each row gets an explicit **Edit** link (NOT whole-row click — the row already has an inline status `<select>` that must stay usable; see §8.4).
- **New page** `admin/book?id=<uuid>` (AdminGate-wrapped, `lang="es"`, reads `?id=` client-side — the established admin pattern). Renders a **`BookDetailEditor`** island.
- **`BookDetailEditor`**:
  - Read-only header: title · author · year · status (context).
  - **Synopsis**: `description_es` / `description_en` textareas + the `TranslateButton` (DeepL), exactly like the promote form's bio fields.
  - **Quotes repeater** (1..N): each entry = `quote_es`, `quote_en` (+ `TranslateButton`), `location`; add / remove with stable monotonic keys (the Stage 8.5 repeater pattern).
  - **Buy-links repeater** (0..N): `retailer` `<select>`, `url`, optional `affiliate_tag`, optional `locale`; add / remove.
  - **Save**: recommend a `SECURITY DEFINER` RPC `set_book_content(p_book_id, p_description jsonb, p_quotes jsonb[], p_links jsonb[])`, `is_admin()`-gated, that atomically updates `books.description_*` and **replaces** the book's `book_quotes` + `book_links` in one transaction (Open decision §8.2). Falls back to sequenced PostgREST writes if an RPC is deemed overkill.

## 6. Public flow — clickable catalog → detail

- **Catalog** (`BookList`): rows link to the detail page carrying the book id.
- **Detail** — a client island fetches the book by id via the **anon** client:
  `books.select("..., authors!inner(name, country_iso_a3, countries!inner(name_es, name_en)), book_quotes(quote_es, quote_en, location, display_order), book_links(retailer, url, locale)").eq("id", id)` — RLS returns it only if the author is published; otherwise a friendly "not found".
- **Renders (read-only)**: cover (`cover_url` if present), title, author name, year, original language, localized country, **status badge** (reuse `CountryPanel`'s `StatusBadge` palette), **synopsis** (`description` in the reader's locale), **quotes** (localized passage + `location`), **buy links**.
- **Buy links**: `<a href={url} target="_blank" rel="sponsored nofollow noopener">` labelled by retailer. The public link uses `url` **as stored** — the admin pastes the complete affiliate URL (tag included). `affiliate_tag` stays an optional internal column for future programmatic tagging and is **not** selected in the anon query (never exposed to visitors).
- **Affiliate disclosure**: a short i18n block near the links, rendered **only when `book_links.length > 0`**.

## 7. URL / render decision — ✅ CONFIRMED 2026-08-26

"Client-rendered (live)" was chosen so a newly-promoted book gets a detail page with **no redeploy**. Static Astro cannot pre-generate `/books/<id>` for books that do not exist at build time.

**Decision:** ship the detail at **`/[lang]/book?id=<uuid>`** — one static page per locale that reads `?id` client-side (matches the admin `?id=` pattern), works identically in `astro dev` and on Cloudflare Pages, and is shareable. The prettier `/books/<slug>` path is deferred to Stage 9 (needs a `books.slug` column + rebuild-on-publish, or a Cloudflare `_redirects` rewrite).

## 8. Risks / open decisions

1. ✅ **URL form** — **CONFIRMED (2026-08-26):** query-param `/[lang]/book?id=` (dev/prod parity, no rebuild). Pretty path deferred to Stage 9.
2. ✅ **Atomic write** — **CONFIRMED (2026-08-26):** a `SECURITY DEFINER` `set_book_content` RPC that atomically updates the synopsis and **replaces** the book's quotes + links in one transaction.
3. **`quote_en` NOT NULL** vs nullable — recommend NOT NULL + DeepL; revisit if single-language passages are common.
4. **Admin entry point** — explicit per-row **Edit** link (recommended) so the inline status `<select>` in `/admin/books` stays clickable; not whole-row navigation.

## 9. DRY / reuse

- Quotes & links repeaters follow the **`BookFields` repeater + stable-key** pattern (Stage 8.5).
- **`TranslateButton`** (DeepL) reused for `quote_en` / `description_en`.
- **`StatusBadge`** (`CountryPanel`) reused for the detail status badge.
- **`book-list.ts` / `BookList`** reused; add the detail link. **`book_links`** + `books.description_*` reused as-is.
- **`email.ts` / Resend** pattern available for the future suggester email.
